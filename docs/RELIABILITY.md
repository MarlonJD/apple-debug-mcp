# Reliability

Apple Debug MCP is a local CLI with an optional menu-supervised daemon mode. It has no hosted availability target, database, or production deployment; daemon state is limited to one user-private endpoint file and in-memory MCP sessions.

## Reliability contract

| Risk or invariant | Detection | Recovery | Verification |
| --- | --- | --- | --- |
| Xcode tool is absent or unavailable | apple_toolchain_status returns a missing path | Install/select the required Xcode toolchain and rerun discovery | make check and MCP smoke output |
| MCP process exits before initialization | Smoke fixture receives no valid initialize response | Run swift build, inspect stderr, and retry the command | scripts/smoke_mcp.sh |
| MCP daemon endpoint is unavailable | Menu-bar supervisor cannot load a healthy user-private endpoint or daemon smoke cannot complete HTTP initialize | Inspect the bundled daemon stderr, remove only a stale `~/Library/Application Support/AppleDebugMCP/endpoint.json`, and rerun `make mcp-daemon-smoke`; do not expose the port beyond loopback | `make mcp-daemon-smoke` and `script/build_and_run.sh --verify` |
| MCP daemon shutdown leaves endpoint metadata | `/shutdown` or menu Quit returns but endpoint metadata remains | Confirm the daemon PID/token match the endpoint file, retry the bounded shutdown, and let the next daemon start remove only its stale owned metadata | `make mcp-daemon-smoke` |
| MCP client session shares or leaks debugger state | A daemon HTTP session can see another client’s debugger sessions, or DELETE/expiry leaves owned LLDB-DAP/kernel-lab adapters alive | Give each MCP server instance its own ToolCatalog.Context and close that context with the HTTP session; reject new sessions after the bounded concurrency limit | ToolCatalogTests and `make mcp-daemon-smoke` |
| LLDB-DAP adapter fails during initialization | apple_lldb_dap_initialize returns an MCP error | Inspect the reported DAP failure; do not launch a target as a fallback | scripts/smoke_mcp.sh |
| Mach-O input is malformed or too large | apple_macho_inspect returns a typed analysis error | Fix the input or reduce scope; never execute the file as a fallback | MachOTests and scripts/smoke_mcp.sh |
| Debug session leaks an adapter process | DebugSessionTests or process inspection finds lldb-dap after close | Close pipes, terminate, force-kill only the owned adapter, and wait | DebugSessionTests |
| LLDB-DAP capability is unsupported by the installed adapter | A named request times out or the initialize capability is absent | Do not expose the request as verified; use the adapter capability report and keep the tool fail-closed | DAP initialize response and fixture smoke |
| Simulator inventory is unavailable or malformed | apple_simulator_list returns a typed error | Verify Xcode/CoreSimulator availability; do not mutate state as fallback | AppleSimulatorTests and smoke |
| Physical-device inventory is unavailable or malformed | apple_device_list returns a typed error | Verify CoreDevice pairing/tunnel state and legacy xcdevice output; keep the transport visible and do not claim CoreDevice authorization for a legacy device | AppleDeviceTests |
| Physical-device legacy lifecycle/debugger is unavailable | apple_device_install, apple_device_launch, or legacy apple_debug_session_create returns a typed transport error | Install ios-deploy, provide the signed `.app` path, and preserve the CoreDevice/legacy distinction; do not fall back to arbitrary shell execution | AppleDeviceTests, LegacyDeviceDebugTransportTests, and connected-device smoke |
| Modern CoreDevice tunnel is listed as disconnected | Paired CoreDevice is not authorized by the initial inventory snapshot | Run the bounded read-only `devicectl device info lockState` refresh; preserve the disconnected state and typed authorization error if the probe fails | AppleDeviceTests and `ios-coredevice-debug-control-smoke` |
| Modern CoreDevice launch does not identify the app process | apple_device_launch returns no `processID` | Pass the signed `.app` path so CFBundleExecutable can be matched in the bounded CoreDevice process inventory; do not guess from a bundle ID when the executable is ambiguous | `ios-coredevice-debug-control-smoke` |
| Modern CoreDevice attach returns before a stable stop | CoreDevice LLDB-DAP `threads`, step, or wait request reports `notStopped` | Use the named `device process attach --pid` attach command, pause, wait for the initial stop, drain stale events, and use a bounded wait after stepping | `ios-coredevice-debug-control-smoke` |
| CoreDevice process action is rejected | `apple_device_processes` or a process mutation tool returns a typed transport, PID, or signal error | Preserve the CoreDevice/legacy distinction, use the positive PID from the bounded inventory, and keep signals inside the allowlist | `AppleDeviceTests` and `ios-coredevice-lifecycle-smoke` |
| Physical sysdiagnose output is unavailable | `apple_device_sysdiagnose` returns a typed path, permission, or CoreDevice error | Use an explicit absolute destination with an existing parent and keep full-log collection opt-in | AppleDeviceService and authorized device smoke |
| Physical xctrace capture is unavailable | `apple_performance_record` returns a typed xctrace or device error | Keep the CoreDevice UUID and signed development target explicit; preserve the trace path and first xctrace diagnostic | physical xctrace probe and performance analysis |
| Menu bar app cannot own the MCP child | Menu bar status becomes failed or the bundled process exits | Open the server log, verify the signed app bundle contains `Contents/Resources/apple-debug-mcp`, and rerun the bundle build script | `script/build_and_run.sh --verify` |
| Xcode project discovery/build fails | apple_xcode_discover or apple_xcode_build returns a typed error | Inspect xcodebuild output and preserve the selected destination; do not run arbitrary shell fallback | AppleXcodeTests and xcode-artifact-smoke |
| Xcode target AST context is incomplete | apple_swift_ast_inspect cannot resolve the selected scheme's module/SDK/source set | Preserve the xcodebuild diagnostics, use explicit source paths as a fallback, and do not label a tree as target-complete | AppleXcodeTests and swift-ast-smoke |
| Xcode build output deadlocks or is incomplete | xcodebuild does not return or app/dSYM artifacts are missing | Keep stdout/stderr file-backed and inspect the typed artifact manifest; do not infer success from a partial log | XcodeService and xcode-artifact-smoke |
| Xcode test result is unavailable | apple_xcode_test completes without a readable xcresult summary | Preserve the result bundle, inspect the first xcodebuild/xcresulttool error, and do not report test counts as known | xcode-test-smoke |
| Apple tool output fills a pipe | A synchronous adapter stops before returning a typed result | Use the bounded file-backed process runner and preserve the first termination/error result | AppleProcessRunner and make check |
| Apple tool process hangs or grows output without exiting | A fixed Apple-tool invocation exceeds its wall-clock deadline or its file-backed stdout/stderr crosses the configured cap | Terminate the owned process, escalate to SIGKILL after a bounded grace period, and return a typed timeout/output error | ProcessRunnerTests and every migrated tool adapter |
| LLDB-DAP sends an oversized or event-heavy stream | A header/body exceeds the framing limit, a partial header grows without a delimiter, stderr exceeds its cap, or buffered events exceed the session limit | Fail the owned DAP session closed and return a typed framing/buffer error; do not continue parsing unbounded data | DAPTests and debugger fixture smoke |
| Debug fixture cannot be prepared | make fixture fails during clang or codesign | Inspect the first toolchain error; do not bypass signing or launch an unverified target | scripts/build_debug_fixture.sh |
| Debugger fixture behavior regresses | debug_fixture_smoke.py fails or leaves a child process | Capture the first MCP/DAP response and rerun cleanup; keep the feature unverified until fixed | make check |
| iOS fixture build regresses | make ios-fixture fails or app bundle/dSYM is missing | Inspect xcodebuild’s first error and preserve the selected Simulator destination | make ios-fixture |
| iOS Simulator fixture leaves state behind | ios-fixture-smoke fails before cleanup | Rerun targeted terminate/shutdown for the known fixture UDID; do not erase the device | make ios-fixture-smoke |
| iOS Simulator debugger attach regresses | ios-debug-fixture-smoke fails or leaves a session/process | Close the owned LLDB session, terminate the known bundle, and shutdown the known UDID | make ios-debug-fixture-smoke |
| Simulator MCP lifecycle regresses | ios-mcp-tool-smoke fails during app info, container, launch flags, or screenshot | Use the known fixture UDID, terminate the fixture bundle, and preserve the first MCP error | make ios-mcp-tool-smoke |
| Semantic UI snapshot is empty | XCUITest attachment is missing or contains no stable identifiers | Keep explicit accessibility identifiers on fixture controls and rerun the standalone MCP UI-tree smoke | make ios-ui-tree-smoke |
| Simulator UI action regresses | XCUITest action probe fails or returns no post-action tree | Preserve the first action failure, terminate the fixture, and rerun one action at a time | make ios-ui-tree-smoke (tap, doubleTap, longPress, typeText, swipe, pinch, wait) |
| Generated arbitrary-app UI probe regresses | Temporary XCUITest runner cannot launch the supplied installed bundle or export its attachment | Preserve the xcresult diagnostic, verify the bundle is installed in the selected Simulator, and keep project-backed UI inspection available separately | ios-arbitrary-ui-smoke |
| Custom-drawn UI action regresses | Coordinate XCUITest action cannot execute or returns no post-action tree | Keep normalized coordinates bounded to 0...1, preserve the screenshot/tree evidence, and do not infer accessibility semantics for custom rendering | ios-ui-tree-smoke and ios-arbitrary-ui-smoke |
| Runtime diagnostic fails or is denied | apple_debug_runtime_diagnose returns a typed policy, tool, permission, or bounded-output error | Keep the target attach grant explicit, narrow the fixed mode/pattern, and preserve raw diagnostics; never fall back to shell execution | runtime-diagnostics-smoke |
| Assembly generation or patching fails | apple_assemble or apple_debug_patch_assembly returns a typed assembler or transactional memory error | Preserve the source/object diagnostic, verify architecture, and keep expected-byte rollback authoritative | assembler-smoke and macOS fixture smoke |
| Reverse or kernel capability is requested | apple_debug_reverse_capabilities or apple_kernel_capabilities reports false support | Use forward stop traces, xctrace, DWARF, vmmap, and user-process runtime diagnostics; do not infer a reversible state or kernel access | reverse-capability-smoke |
| CFG/shared-cache analysis is unavailable | apple_control_flow or apple_dyld_shared_cache_inspect returns a typed parser/tool/input error | Preserve the artifact and use Mach-O/symbol/DWARF analysis; discovery separately reports mounted cache files versus public runtime helpers; do not execute or rewrite the cache | control-flow-smoke and dyld-cache-smoke |
| Typed memory snapshot fails | apple_debug_memory_analyze/snapshot/diff returns a typed vmmap, path, or JSON error | Keep attach authorization explicit and preserve raw vmmap separately | memory-map-smoke |
| Simulator environment operation fails | apple_simulator_environment rejects a value, permission, payload, or simctl operation | Narrow to a fixed supported operation and clean only the selected Simulator state | simulator-environment-smoke |
| Repro bundle is incomplete | apple_simulator_repro_bundle cannot capture a screenshot, metadata, logs, or bounded attachments | Preserve the first artifact failure and keep the output directory for inspection; never infer completeness | repro-bundle-smoke |
| Signing/patch workflow fails | Signing audit, patch preview, or re-sign plan returns a typed artifact/tool error | Keep release mutations outside MCP and use the explicit plan/release script after human authority | signing-audit-smoke and patch-workflow-smoke |
| Workbench/plugin surface regresses | SwiftUI workbench fails to build or plugin manifest discovery rejects valid metadata | Keep MCP core usable independently; repair the native target or manifest contract | workbench-build-smoke and plugin-smoke |
| Plugin host validation regresses | apple_plugin_host_plan or apple_plugin_host_execute cannot audit a candidate signer/team or returns an unsafe sandbox result | Keep execution disabled, preserve the separate host boundary, and require explicit grant/timeout/output limits | plugin-smoke |
| Plugin XPC service regresses | apple_plugin_host_execute cannot connect to or decode the independently signed App Sandbox XPC service | Keep XPC execution unavailable, preserve manifest/signature evidence, and use the explicit legacy profile only for local diagnostics | plugin-xpc-smoke and plugin-smoke |
| Tool output becomes non-deterministic | Core tests or sorted JSON output changes unexpectedly | Reproduce with the same fixture and update the contract intentionally | swift test |
| Debugger operation leaves a target or adapter running | Fixture smoke fails or process inspection finds an owned child | Close the session and rerun targeted cleanup; do not kill unrelated processes | macOS and iOS Simulator fixture smoke |
| Stop snapshot is incomplete | apple_debug_stop_snapshot lacks events, threads, stack, registers, or modules | Preserve the raw DAP response and inspect adapter capabilities before adding another request | macOS fixture smoke |
| Stop event is not observed after control | apple_debug_wait_for_stop returns timedOut without a stopped/exited/terminated event | Keep the session open, inspect buffered events, and retry with a bounded timeout; legacy physical sessions additionally use throttled `threads` state polling and mark the observation `adapter-state-poll`, while CoreDevice sessions synchronize initial/step stops before issuing inspection requests | macOS fixture smoke, ios-legacy-debug-control-smoke, and ios-coredevice-debug-control-smoke |
| LLDB-DAP EOF races with process status | Adapter EOF arrives while Process still reports running | Read terminationStatus only after an isRunning guard and return a typed process status instead of crashing the MCP server | make check and fixture smoke |
| Memory map is unavailable | apple_debug_memory_map returns a typed vmmap/tool permission error | Keep the operation local and attach-gated; preserve the target PID and first vmmap diagnostic | DebugSessionTests and MCP smoke schema |
| Performance trace is unavailable or unparseable | apple_performance_record, apple_performance_analyze, apple_performance_semantic_report, or apple_swift_concurrency_graph returns a typed xctrace, permission, export, or output error | Keep template, target, duration, schema, per-table row count, and `.trace` path bounded; template reports and the public Swift Concurrency graph remain unavailable when their tables are empty or over the 32 MB export cap | performance-analysis-smoke and swift-concurrency-graph-smoke |
| Memory patch verification fails | apple_debug_patch_memory cannot read back requested bytes | Roll back expected original bytes when possible and keep the result unverified | DebugPolicy and patch transaction path |
| Variable mutation is rejected | apple_debug_set_variable returns the explicit policy error | Keep the target stopped and enable the separate variable-write grant only for an authorized debugging session | DebugSessionTests and macOS fixture smoke |
| Crash report is malformed or unsupported | apple_crash_inspect returns a typed analysis error | Preserve the artifact and inspect it with the supported `.crash`/`.ips` parser | CrashReportTests |
| Crash frame has no matching artifact | apple_crash_symbolicate reports unmatchedFrameCount or a per-frame error | Supply an imageName-to-binary/dSYM mapping and preserve unmatched frames instead of guessing | CrashReportTests and MCP smoke |
| Apple binary intelligence tool is unavailable or noisy | apple_binary_inspect returns a typed command/size error | Inspect the first codesign/otool/nm/dyld_info error and keep the artifact unexecuted | AppleBinaryIntelligenceTests and MCP smoke |
| Runtime metadata tool is unavailable or noisy | apple_runtime_metadata returns a typed command/size error | Preserve the binary and rerun the focused Objective-C/Swift metadata test | AppleRuntimeMetadataTests |
| DWARF input is missing, malformed, or too large | apple_dwarf_inspect returns a typed input, command, or bounded-output error | Preserve the Mach-O/dSYM, narrow the name/depth query, and do not infer type/source data from symbols alone | dwarf-smoke and `DWARFService` |
| Binary diff cannot resolve an artifact | apple_binary_diff returns an artifact or bounded-tool error | Keep the inputs unexecuted, verify the `.app`/`.dSYM` layout, and rerun the focused diff test | AppleBinaryDiffTests and MCP smoke |
| Unified log query is too broad or unavailable | apple_log_show returns a bounded-output or command error | Narrow duration/predicate and verify host/Simulator logging availability | AppleLogsTests and tool error path |
| Simulator screenshot cannot be written | apple_simulator_screenshot returns a typed command error | Use a writable PNG path and keep the Simulator mutation gate explicit | SimulatorService and iOS fixture smoke |
| Simulator recording or location control fails | apple_simulator_record_video or location tools return a typed command error | Keep the selected UDID and output path explicit; use the current public simctl default codec (`hevc`) unless a supported override is required, preserve the first simctl diagnostic, and clean generated media | ios-mcp-tool-smoke |
| Signed release validation fails | make release-package reports a codesign, notarization, staple, or Gatekeeper error | Preserve the release staging artifact path from the first failure, inspect the exact signing/notary diagnostic, and do not publish the zip until all three validations pass | scripts/release_macos.sh and docs/RELEASE.md |
| Unsigned package cannot be produced | make package or the release SwiftPM build fails | Inspect the first SwiftPM/archive error; signing and notarization are separate release steps | scripts/package_macos.sh |
| Hosted availability, failover, and production rollback | Not applicable to the current local-only daemon | N/A; the daemon is loopback-only and has no hosted availability target | N/A |

## Failure policy

The server fails closed for unknown tools and reports missing allowlisted tool paths as data. It must not fall back to arbitrary shell execution or silently broaden target permissions.
